# v0.13.2 - Added videos are reviewed like any other

- **Videos you add are AI-checked by default.** A custom playlist now starts with **Check with AI** switched on, so a video you pick, by search or by link, is reviewed when it plays, like every other video, whenever AI screening is enabled. With screening off, nothing changes. Switch the playlist's 📝 dialog off if you fully trust it.
- **Playlists you already made keep their setting.** Open the 📝 on a playlist and switch **Check with AI** on if you'd like it reviewed too.

Install the signed `pickwick.apk` below to update without losing settings.
