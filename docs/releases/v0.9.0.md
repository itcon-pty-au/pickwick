# v0.9.0 - Network libraries and content limits

- Stream your home video collection from SMB2/3 network shares, including router USB drives and NAS devices.
- Save a network connection once, then add multiple catalog folders. Browse shows, seasons and episodes with cached listings and thumbnails.
- Manage YouTube and network libraries together under Content Sources, with per-child access.
- Create content groups spanning YouTube and network catalogs, with per-child, per-session time allowances.
- Use Favorites, Watch later and Up next with network videos, and select embedded audio and subtitle tracks.
- Improved TV folder sizing, initial video focus and thumbnail generation.
- Reduced SMB playback round trips with read-ahead buffering; thumbnail extraction pauses during playback.
- Content-session timers appear only while player controls are visible.

Content allowances are enforced per device; usage is not synchronized between devices.

Install the signed `pickwick.apk` below to update without losing settings.
