# v0.13.0 - Live streams

- **Add a live stream like any video.** Paste a live link (for example a 24/7 show) into the channels box and put it in a custom playlist. The app checks the link first: a video that can't be played in the app is refused with a message, and a live one is remembered as live.
- **A Live row on the TV.** Live streams that are on air right now get their own **Live** row on the home screen, under Podcasts. Press OK to watch. The row only appears while something is live.
- **LIVE and Offline badges.** In its playlist a live stream wears a small red **LIVE** badge. When it goes off air, or stops playing, the tile dims, reads **Offline** and can't be opened until it's back. The app re-checks live items each time it opens, at most every 10 minutes.
- **No error screen.** If a picked video can't play, the app goes back to the list (or on to the next video in the queue) instead of stopping on an error.
- **No key needed.** The check uses the same extractor as playback, so there is nothing to set up.
- **AI note icon fixed.** The 📝 icon is bright when AI checking is on for a channel or custom playlist and dim when it's off. It was the other way round.

Install the signed `pickwick.apk` below to update without losing settings.
