# v0.14.2 - Live streams in one place

- **No more duplicate live streams on the TV.** A stream you added to a custom playlist now appears only in the **Live** row, not in the playlist as well. It shows there while it's on air and stays out of sight when it isn't.
- **Playlists with only streams.** On the TV, a custom playlist holding nothing but live streams no longer gets a home screen tile, because it would open onto an empty page.
- **Phones are unchanged.** Phones have no Live row, so streams stay in their playlist with the **LIVE** badge. A stream in a YouTube channel's own feed also stays in that channel on the TV.

Install the signed `pickwick.apk` below to update without losing settings.
